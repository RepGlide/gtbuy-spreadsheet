Five-Field Order Note

Record Five Fields, Not a Blob

A clear note has five fields. Each field keeps one idea, so nothing is left vague.

  • 01
    Item reference

    A neutral identifying clue for the current candidate — enough to find it again, nothing more.

  • 02
    Source URL

    The source page you will actually reopen to re-check the item.

  • 03
    Variant

    The color, size, version, or style — written out explicitly.

  • 04
    Quantity

    The current planned quantity. Planning a number is not the same as placing an order.

  • 05
    Check before submit

    What still needs confirming — price, option, availability, and rules.

Planning example — not an order, live data, or a saved record.

Sheet Can / Cannot Tell You

What the Sheet Can and Cannot Say

✓The Sheet can tell you

  • Where to look — a category and a link.
  • A reference name for a candidate.
  • A starting point for your own note.

✕The Sheet cannot tell you

  • That an item is as described.
  • Live price, stock, or availability.
  • That your planned quantity is confirmed.
Make Ambiguity Visible

A Vague Note Hides Work

Write the note so the next reader — including future you — knows exactly what is meant.

✕Vague note

  • “the blue one, maybe two.”
  • “the one I saw earlier.”
  • “size? check later.”

✓Clear note

  • Color: navy — Size: M — Qty: 2.
  • Item reference + source URL written out.
  • Size still to confirm, marked in the check field.

Before You Leave the Desk

A Final Pass Before You Go

  • 01

    Every candidate has a note. No find is left as a bare row.

  • 02

    Variants are explicit. Color, size, version, and quantity are written out.

  • 03

    Open items are marked. Anything unconfirmed is in the check field, not hidden.

    The plan stays limited. It is a plan, not a live order.

FAQ

Frequently Asked Questions

What is a GTBuy spreadsheet?

A GTBuy spreadsheet is a shared document that compiles listing references, category groupings, and product links formatted for use with agent shopping services. Each row is a candidate clue for planning, not a live product record.

Is this website the official GTBuy service?

No. This website is an independent informational and navigation resource. It is not affiliated with, endorsed by, or operated by GTBuy or Google.

Does the order note place an order or provide tracking?

No. The order note is a personal planning aid. It does not place orders, store account data, provide tracking, or act as a store, order system, quote tool, or logistics tool.

How do I use the GTBuy spreadsheet to build an order plan?

Open the shared Google Sheet and browse the category links to build a shortlist, then record each candidate as a five-field order note: item reference, source URL, variant, quantity, and what to check before submitting.

What should I record in a variant note?

Record the color, size, version or style, and quantity clearly, plus the source URL and anything still to confirm — price, option, availability, and rules. Keep the note unambiguous.

Where do I place an order after preparing my plan?

After preparing your order plan and re-checking the source page, you can continue through an agent shopping service to submit the item. This website is a navigation resource and does not process orders itself.
