Variant Order Note Guide

Record color, size, quantity, and style clearly — so a note never hides an ambiguous choice.

Why clarity matters

A vague note costs you the re-check later. The point of a variant note is that future you — or whoever reads it — knows exactly what was meant, without guessing.

Color

Write the color exactly as the listing names it. “Blue” is ambiguous; the listing’s color name is not.

Size

Write the size or sizing label exactly. Sizes differ between sellers and regions, so record the label, not a guess.

Version or style

When a listing splits into versions or styles, record which one you mean. An older batch and a revised model are different items.

Quantity

Write the planned number. A planned quantity is not an order — it is a target to confirm before submitting.

Margin noteRecord the listing’s own labels, not your paraphrase. Exact labels survive re-checking.

Vague vs clear

  • Vague: “the blue one.” — Clear: Color: Navy / Size: M / Qty: 2.
  • Vague: “maybe two.” — Clear: Quantity: 2 (to confirm).
  • Vague: “check size later.” — Clear: Size: unconfirmed — marked in check field.
?Open item: is every field in this note written exactly, with anything unclear marked for checking?

A worked note

  1. Item reference: a short neutral identifier for the candidate.
  2. Source URL: the page to reopen.
  3. Variant: Color: Navy — Size: M.
  4. Quantity: 2 (planned).
  5. Check before submit: price and availability still to confirm.

Planning example — not an order, live data, or a saved record.
