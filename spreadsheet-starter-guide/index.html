Spreadsheet Starter Guide

Pick a category, read a clue, and build a shortlist on your first pass through the GTBuy spreadsheet.

Start with one category

The GTBuy spreadsheet is large. Begin with a single category so your first pass stays manageable. A category groups rows that belong together, which makes reading and shortlisting easier.

Read a clue for what it is

A row is a clue: a reference name, a category, and a link. It is not live product data. Read it as a pointer toward a source page you will reopen later.

Margin noteA row points somewhere. The closer you keep it to the source page, the less you depend on someone else’s snapshot.

Build a shortlist

Copy only the candidates worth checking into a short, reviewable list. Note where each came from, and keep the list small enough to finish.

  1. Choose one category.
  2. Pick the rows that match what you are looking for.
  3. Note each row’s origin.
  4. Stop when the list is short and reviewable.
?Open item: does every row in your shortlist have a reason to be there?

A worked first pass

  1. Category: you open Bags and skim the grouped rows.
  2. Candidates: you copy three rows that match the style you want.
  3. Origin: each row is marked with where it came from.
  4. Hand off: the shortlist is ready for order notes.

Planning example — not an order, live data, or a saved record.
