About This Resource

An order desk and haul ledger built around a shared GTBuy spreadsheet.

What this resource is

This is an independent informational and navigation resource for people who use a GTBuy spreadsheet. It helps you turn shortlisted links into a clearer personal order plan using a five-field order note — item reference, source URL, variant, quantity, and what to check before submitting.

What this resource is not

This resource is not the official GTBuy website, and it is not affiliated with, endorsed by, or operated by GTBuy or Google. It is not a store, an order system, a quote tool, or a logistics tool.

The five-field note

Everything here is organized around five fields: Item reference, Source URL, Variant, Quantity, and Check before submit. They are a planning aid, not an order. A planned quantity is not a placed order.

How to use it

  1. Open the shared Google Sheet to see the listing references.
  2. Browse the twelve product categories from the home page.
  3. Read the three guides before relying on any listing clue.
  4. Record your own notes and re-check the source page yourself.

Planning example — not an order, live data, or a saved record.
